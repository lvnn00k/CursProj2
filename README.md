## Краткое описание программы
    Программа позволяет создавать чек с несколькими позициями. Каждая позиция состоит из товара и количества. Также можно удалить позицию чека или вывести все существующие. 
    Список товаров:
    |Название   |Цена  |НДС |
    |-----------|------|----|
    |One        |100   |22  |
    |Two        |200   |0   |
    |Three      |300   |22  |
